# სერვოს ღილაკები

ცალკე, ერთეკრანიანი საიტი სამი ღილაკით: თითო ღილაკი თითო სერვოს ხსნის (სერვო 1 = D3, სერვო 2 = D5, სერვო 3 = D6). სერვო 5 წამში თავისით იკეტება, ამ დროს ღილაკი მწვანეა და ათვლას აჩვენებს. ღია სერვოზე ხელახლა დაჭერა დროს თავიდან იწყებს.

Hospes-ის კოდს არ ცვლის. Arduino-ს Hospes-ის სერვერი ფლობს, ეს საიტი კი მის არსებულ მარშრუტებს იყენებს (დემო ადმინის ანგარიშით): დაჭერა `POST /api/admin/locks/<n>/open`-ს აგზავნის, მდგომარეობას კი `/api/admin/rfid/stream`-დან კითხულობს. ამიტომ Hospes-ის სერვერიც უნდა მუშაობდეს:

```bash
npm run dev
```

შემდეგ ამ საიტის გაშვება (Node 22+, დამატებითი პაკეტები არ სჭირდება):

```bash
node servo-buttons/server.js
```

- ლეპტოპზე: http://localhost:5501 (კლავიშები 1, 2, 3 ღილაკებს აჭერს)
- ტელეფონზე იმავე Wi-Fi-ზე: `http://<ლეპტოპის-IP>:5501`. მისამართს სერვერი გაშვებისას წერს. პაროლი არ სჭირდება, ამიტომ იმავე ქსელში ნებისმიერს შეუძლია დაჭერა: ეს მხოლოდ დემოსთვისაა.

ქვედა ხაზი კავშირს აჩვენებს: „მზადაა“, ან რა აკლია (Hospes-ის სერვერი, Arduino). თუ Hospes-ში `ARDUINO_PORT` ცარიელია, საიტი დემო რეჟიმში მუშაობს: ღილაკები ფერს იცვლის, სერვოები კი არ მოძრაობს.

პარამეტრები (არასავალდებულო): `SERVO_BUTTONS_PORT` (5501), `HOSPES_API` (`http://localhost:4000/api`), `HOSPES_EMAIL`, `HOSPES_PASSWORD`.
