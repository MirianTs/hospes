# 4 სერვოს ლოქერი

Arduino Uno + 4 SG90 სერვო + საიტი 4 ღილაკით. ღილაკზე დაჭერა სერვოს 90°-ით აბრუნებს (ღიაა), 5 წამში თავისით ბრუნდება 0°-ზე (დაკეტილია). მე-3 საკეტი სარკისებურია: დაკეტილი 180°, ღია 90°.

ყუთის 3D ფაილები (3 კარი + სერვოიანი სახურავი): პირად რეპოში `MirianTs/3d-print-files`, საქაღალდე `locker-box/`.

## შეერთება

| საიდან | სად |
|---|---|
| Uno 5V | ბრედბორდის + რელსი |
| Uno GND | ბრედბორდის − რელსი |
| ყველა სერვოს წითელი | + რელსი |
| ყველა სერვოს ყავისფერი | − რელსი |
| სერვო 1 ნარინჯისფერი | D3 |
| სერვო 2 ნარინჯისფერი | D5 |
| სერვო 3 ნარინჯისფერი | D6 |
| სერვო 4 ნარინჯისფერი | D9 |

კვება მხოლოდ USB-დანაა, ამიტომ სკეჩი სერვოებს რიგრიგობით ამოძრავებს და მოძრაობის შემდეგ ათავისუფლებს. თუ 470–1000 µF კონდენსატორი გაქვს, ჩასვი + და − რელსებს შორის (გრძელი ფეხი +-ზე).

## ჩატვირთვა

1. Arduino IDE-ში გახსენი `hardware/servo-locker/servo_locks/servo_locks.ino`.
2. Tools → Board: Arduino Uno, Tools → Port: Uno-ს COM პორტი.
3. Upload.

## საიტი

`index.html` გახსენი Chrome-ში ან Edge-ში → „Arduino-სთან დაკავშირება“ → აირჩიე პორტი. კლავიშები 1–4 ღილაკებს აჭერს.
Serial Monitor დახურული უნდა იყოს, თორემ პორტი დაკავებულია.
