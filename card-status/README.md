# ბარათის სტატუსი

ცალკე, ერთეკრანიანი საიტი: აჩვენებს მხოლოდ იმას, კარი ღიაა თუ დაკეტილი. ბარათის მიდებისას ეკრანი მწვანდება („ღიაა“, 5 წამის ათვლით) და კარის დაკეტვისას ისევ დაკეტილ მდგომარეობას უბრუნდება. უცნობ ბარათზე წამიერად „წვდომა აკრძალულია“ ჩნდება, თუ Hospes-ში ჩართულია „მხოლოდ დაშვებულს“.

Hospes-ის კოდს არ ცვლის. Arduino-ს Hospes-ის სერვერი ფლობს, ეს საიტი კი მის ცოცხალ არხს კითხულობს (`/api/admin/rfid/stream`, დემო ადმინის ანგარიშით). ამიტომ Hospes-ის სერვერიც უნდა მუშაობდეს:

```bash
npm run dev
```

შემდეგ ამ საიტის გაშვება (Node 22+, დამატებითი პაკეტები არ სჭირდება):

```bash
node card-status/server.js
```

- ლეპტოპზე: http://localhost:5500
- ტაბლეტზე ან ტელეფონზე იმავე Wi-Fi-ზე: `http://<ლეპტოპის-IP>:5500`. მისამართს სერვერი გაშვებისას წერს.
- სხვა კარისთვის: `http://localhost:5500/?lock=2`

**ხმა:** გაღებისას ამომავალი ზარი ისმის, დაკეტვისას დაღმავალი, უარყოფისას დაბალი ორმაგი სიგნალი. ბრაუზერი ხმას მხოლოდ გვერდზე პირველი შეხების შემდეგ რთავს, ამიტომ გახსნისას ერთხელ შეეხეთ ეკრანს. ზედა კუთხის ღილაკით ხმა ირთვება და ითიშება.

ქვედა ხაზი კავშირს აჩვენებს: „მზადაა: მიადე ბარათი“, ან რა აკლია (Hospes-ის სერვერი, Arduino, RFID მკითხველი).

პარამეტრები (არასავალდებულო): `CARD_STATUS_PORT` (5500), `HOSPES_API` (`http://localhost:4000/api`), `HOSPES_EMAIL`, `HOSPES_PASSWORD`.
